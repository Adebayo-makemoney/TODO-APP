# ✅ TODO App

A simple, elegant, and responsive **To-Do List Application** built using **HTML**, **CSS**, and **JavaScript**.  
This project helps users manage daily tasks efficiently with real-time updates and persistent local storage.

---

## 🌍 Live Demo

👉 **[View the App](https://adebayo-makemoney.github.io/TODO-APP/)**

---

## ✨ Features

- ➕ Create, read, update, and delete tasks (CRUD)
- ✅ Mark tasks as completed
- 💾 Saves tasks in **local storage** (data persists even after reload)
- 🧭 Filter tasks by status (All, Completed, Pending)
- 🌓 Light/Dark mode toggle
- 📱 Fully responsive design for all devices

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/Adebayo-makemoney/TODO-APP.git

# Navigate to project folder
cd TODO-APP

# Open in browser
start index.html
```
